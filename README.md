### 一、桌面视觉、主题与背景美化

> 打造专属个性化桌面，从视觉主题到交互体验全面升级，让飞牛焕然一新。

**🌈 全场景个性化主题定制**
- 动态视频背景（推荐 H264 的 MP4）、随机桌面壁纸，支持自定义壁纸外链 URL、第三方壁纸 API
- 背景新增渐变过渡动画，视觉效果更加流畅自然
- 内置多套系统复刻主题：Win98 / WinXP / Win7 / Win10 / Win11 / Mac，桌面右键一键切换
- 全局磨砂毛玻璃界面，支持全窗口毛玻璃特效
- 登录背景、桌面背景完全分离，可独立自定义配置
- 全套 LOGO 自定义：页面主 LOGO、登录页 LOGO、文件收集页 LOGO、社交分享页 LOGO 共用一套配置
- 支持自定义网页 favicon、登录框透明度、登录框位置自由调节
- 登录页面可填写 ICP、公安备案信息，适配顶级域名部署
- 支持Web端登录安全入口，让顽皮的小精灵束手无策
- 内置在线主题库，多套预设主题支持实时预览一键应用

**👑 窗口、任务栏交互增强**
- 任务栏支持底部横置布局，优化高度，默认居左展示
- 所有桌面窗口、文件夹统一复用飞牛原生托盘任务栏，旧版独立任务栏彻底下线
- 解除飞牛窗口最小尺寸限制，窗口支持拖拽缩放、双击最大化、最小化至托盘
- 优化窗口层级渲染，解决窗口互相遮挡、最大化边缘错位问题
- 拖拽边界限制在可视页面内，避免拖出页面丢失
- 飞牛应用窗口内置刷新按钮、独立跳出新窗口按钮
- 图标躲避模式：鼠标靠近图标自动避让，按住 Ctrl 键可临时关闭

### 二、图标、文件夹 & Docker 管理（替代浏览器收藏夹）

> 全面掌控桌面图标与文件夹，支持自由拖拽排序和多设备同步，完美替代浏览器收藏夹。

**✨ 图标与文件夹完整自由管控**
- 桌面图标、多层级文件夹支持自由拖拽排序，多设备配置自动同步
- 后台图标管理页也支持拖拽排序，管理更便捷
- 每个图标、文件夹配备独立显示开关，灵活控制展示
- 点击页面左上角小图标可一键隐藏 / 显示全部桌面图标
- 完美兼容中文图标名称无乱码，支持自定义图标排序规则（序号越大越靠前，支持正反序切换）
- 原生图标生成大幅升级：不再限制 PNG 格式、单文件 1MB 大小
- 链接自动补全 HTTP/HTTPS 协议，支持本地镜像图标展示
- 海量离线图标库迭代：V2 新增 700 枚图标、V3 新增 26000 枚图标
- 图标管理页顶部提供一键导入原创图标按钮，支持自定义系统内置图标
- Docker 图标持续迭代升级至 V6：统一 docker 文件夹存放图标，取消多目录分离
- 容器列表、日志页、终端详情页全部显示自定义图标，完美适配本地镜像
- 提供一键批量添加 Docker 容器图标功能，效率大幅提升
- 图标完美适配飞牛 APP、FN Connect 跨端访问
- 社交分享卡片可自定义网站标题、描述、图标
- 支持批量上传本地图标，远程图片保存至本地
- 新建图标默认关闭拖拽排序、绿色功能开关
- 空链接条目自动隐藏，精简界面
- 删除文件夹自动迁移内部图标，不产生无归属孤立图标
- 卸载原生图标不会残留空文件夹

**🌐 内外网智能链接 & 外链分享**
- 自动识别内网 / 公网网络环境，多组自定义链接根据网络自动切换地址
- 链接可单独自定义 HTTP/HTTPS 协议前缀
- 链接支持仅填写端口号快速拼接完整地址，优化 URL 解析逻辑
- 缩短内外网判断超时时间，提升响应速度
- 默认启用飞牛统一网关，同时兼容独立端口访问、CGI 两种模式，突破端口访问限制
- HTTP 与 HTTPS 可共用同一个端口，减少端口占用
- 外链分享全端自定义：PC、移动端独立 LOGO、标题、简介、跳转链接
- 相册、影视页面同步适配社交分享卡片，自定义预览信息

### 四、Fndesk Music 桌面音乐播放器 🎵

> 完整独立的桌面音乐播放器，支持无损格式、快捷键操作和多目录管理，让音乐体验更沉浸。

- **播放体验**：完整独立音乐播放器，桌面常驻播放，支持飞牛 APP 后台连续播放
- **格式支持**：支持无损音频格式，优化无损解码内存占用，音质无损享受
- **目录管理**：支持多音乐目录批量导入，播放列表维持开关状态
- **快捷键全功能支持**：
  - 空格 / 点击封面：播放暂停
  - 左右方向键：快进快退
  - 上下方向键：调节音量
  - N/P：上 / 下一曲
  - S/R/L：随机播放 / 循环 / 显示歌词
  - ESC：清空搜索框，回车执行搜索
- **记忆功能**：记忆上次播放曲目、播放进度、歌词显示行数，记忆播放器窗口打开位置
- **歌词支持**：支持 LRC 歌词、MP3 内嵌歌词，拖拽进度条跳转，播放失败自动切下一首
- **UI 定制**：播放器独立多款 UI 皮肤，新增返回顶部按钮
- **文件关联**：文件管理直接右键打开音乐文件调用播放器，支持设置音乐文件默认打开方式
- **安全访问**：播放器支持密码访问开关，隐藏播放器访问权限
- **分享适配**：播放器页面可自定义标题、LOGO，适配分享卡片

### 六、安全、备份、密码与 HTTPS

> 全方位保障数据安全，支持备份还原、HTTPS 部署和密码管理，让使用更安心。

- **密码管理**：删除 `deskdata` 目录内 `pw.json` 文件，下次访问重新初始化管理员密码
- **HTTPS 部署**：证书放置 `deskdata/ssl` 目录（`server.crt` + `server.key`），重启程序生效；HTTP/HTTPS 共用单一端口
- **配置存储**：配置全量存储在 `deskdata` 目录，支持手动备份、迁移、还原
- **一键还原**：后台带配置预览，提供在线一键还原脚本、系统中招检测脚本，还原完成无需重启程序
- **安全加固**：提升程序安全等级，修复密码文件暴露风险，修复 EISDIR 异常导致程序闪退
- **缓存优化**：新增强制立即生效逻辑，多数修改无需手动保存；解决浏览器缓存不更新问题

## <span style="color:#4ecdc4">使用说明</span>
* 🍭 有兴趣的灵魂请加入Q群组1039270739参与讨论  
  本工具是一个单纯的修改工具,修改配置生效后可以停用甚至卸载本工具,重启也能一直生效
  
* 🍔 大致使用流程：修改操作>保存配置>立即生效(>清理缓存)  
  (保存和生效是分开, 配置保存后, 就算还原或系统升级,只要重新保存应用即可)

* 🍟 配置文件都在deskdata目录里, 要备份还原移植配置都可以的。  
  (Docker Compose的配置目录在Compose文件同在的目录下,  
  飞牛应用中心安装的配置文件在[文件管理]>应用文件>fndesk目录里)

* 🥤 不生效? 99%的不生效都是缓存造成的, 清理缓存和强制刷新(Ctrl+F5)不太好使  
  建议用浏览器的无痕模式, 或者按F12进入开发者模式到 网络 里把 禁用缓存 勾选上

* 🍦 忘记密码?  
  只需删除deskdata目录里面的pw.json文件即可访问时重新初始化密码

* 🧀 启用HTTPS?
  把证书放在deskdata/ssl目录(server.crt和server.key) 然后重启程序即可
